# ProntoFix (Home Master) — учёт и управление сервисом бытовой техники и мелких ремонтов

Сервер (Python) + веб-интерфейс (работает в браузере) + Android-приложение (оболочка над тем же интерфейсом). Языки: русский, украинский, английский, португальский — новый язык добавляется одним файлом.

## Что внутри
| Папка / файл | Назначение |
|---|---|
| `server/` | Сервер (FastAPI): роли, заказы, финансы, склад, маршруты, чат, файлы, графики, Excel. `manage.py` — служебные команды |
| `web/` | Веб-интерфейс (`/app/`): тот же во всех браузерах и в Android-приложении |
| `android/` | Android-приложение 5.0+ (нативная оболочка). `./build_apk.sh` → `HomeMaster.apk`. См. `android/README_ANDROID.md` |
| `truenas/` | Установка на **TrueNAS CORE** (jail) — `truenas/INSTALL_TRUENAS_CORE.md` |
| `docs/INSTALL_TRUENAS_SCALE.md` | Установка на **TrueNAS SCALE** (Docker) |
| `START_HomeMaster_Web.bat` | Проверка на Windows одним щелчком (сервер + браузер + демо-данные) |
| `tools/` | `seed_demo.py` (демо-данные), `test_server.py`/`test_server2.py` (автотесты), `check_locales.py` |

## Роли (права проверяются на сервере)
| № | Роль | Возможности |
|---|---|---|
| 1 | Владелец | всё; назначает администраторов и меняет роли |
| **7** | **Администратор** | назначается владельцем **внутри приложения**; администрирует сервер с телефона и ПК: оформление, отчёты, финансы, склад, файлы, сотрудники, подрядчики, графики |
| 2 | Начальник отдела | заказы своего направления, назначение исполнителей, премии/штрафы, склад, приглашение подрядчиков |
| 3 | Исполнитель (штат или подрядчик) | заказы, карта и маршруты, трекинг, склад, чат, расходы и часы по заказу |
| 4 | Заказчик | заказы, остаток предоплаты и списания, оценка работы, свои работники |
| 5 | Работник заказчика | создаёт заказы |
| 6 | Наблюдатель | только чтение (в т.ч. графики и чат) |

## Возможности
* **Оформление:** 20 готовых скинов; любой пользователь создаёт свой (цвета из палитры + шрифт). Скин **не меняет** масштаб, расположение кнопок/значков, функции и логику. Администратор задаёт скин по умолчанию, общие скины и название приложения.
* **Excel-отчёты** (заказы, оплата сотрудников, предоплата, склад, маршруты): колонки **«компания исполнителя»** и **«компания заказчика»**, занятость (штат/подрядчик), деньги, километры; заголовки на языке интерфейса. Сохранение — с выбором папки/носителя.
* **Графики** по всем заказам: 9 видов (комбинированный, столбцы, с накоплением, горизонтальные, линия, область, круговая, кольцевая, «зависимость» с коэффициентом корреляции). Разрезы: время (час/день недели), дата, неделя, месяц, компания заказчика, исполнитель, компания исполнителя, вид услуги, направление, статус, занятость. Показатели: заказы, выручка, себестоимость, маржа, часы, км, оценка, **остаток предоплаты**. Графики накладываются слоями с цветом каждого слоя из палитры; настройки сохраняются.
* **Финансы:** предоплата заказчика → списание за услугу уменьшает остаток; **себестоимость** = материалы (со склада) + транспорт (км × цена км) + прочее + оплата исполнителю; маржа. **Оплата сотрудников:** штат — фиксированная ставка (в час / за заказ), подрядчики — % от прибыли; **премии и штрафы**.
* **Подрядчики:** приглашение по коду → регистрация (компания, ИНН, документы) → проверка администратором; до проверки заказы недоступны. Штатные сотрудники идентифицируются по правилам компании (табельный номер, компания).
* **Карта исполнителя:** заказы на карте, выбор нескольких, **маршрут с километрами и стоимостью транспорта**, «взять в работу», **трекинг** (фактические километры и уточнение координат объекта по GPS сохраняются для будущих расчётов), «Прибыл».
* **Администратор видит всех сотрудников на карте** (в сети / не в сети, контакты, трек за день).
* **Склад:** материалы и оборудование, остаток на складе и «на руках» у сотрудников, у кого деталь и где он, звонок/чат; движение (поступление, выдача, передача, возврат, списание на заказ), описание, фото и видео; отчёт о движении.
* **Чат сотрудников:** текст, фото/видео/документы, геопозиция, деталь со склада; история на сервере. **Хранилище файлов** (администратор): все файлы сервера, сортировка по дате/размеру/имени/отправителю, удаление любого файла. Файлы можно брать из любого места устройства.

## Быстрый старт
* **Проверить на Windows:** `START_HomeMaster_Web.bat` (Python 3.10+). Логины и сценарии — `docs/README_WEB_WINDOWS.txt`.
* **Сервер на TrueNAS:** CORE — `truenas/INSTALL_TRUENAS_CORE.md`; SCALE — `docs/INSTALL_TRUENAS_SCALE.md`.
* **Android:** `HomeMaster.apk` → установить → ввести адрес сервера. Сборка своего APK — `android/README_ANDROID.md`.
* **Тесты:** `cd server && PYTHONPATH=. python ../tools/test_server.py && PYTHONPATH=. python ../tools/test_server2.py`

## Безопасность и ограничения
* Паспортные данные хранятся зашифрованными, видны только владельцу и администраторам; просмотр пишется в журнал. **Сохраняйте `SECRET_KEY`** (иначе не расшифровать).
* Загружаемые файлы проверяются по типу: исполняемые, html/js/svg запрещены; не-медиа файлы отдаются как скачиваемые.
* Для работы из интернета и мобильного приложения нужен **HTTPS**. Тайлы Google нельзя качать массово для офлайна.
* **Фоновый трекинг:** положение пишется, пока приложение открыто (экран не гаснет). Для работы со свёрнутым приложением нужна нативная служба — не реализовано.
* Android-приложение собрано и подписано, но на реальном телефоне мной не запускалось. Установка на TrueNAS CORE/SCALE также проверялась без реального NAS.
* Построение маршрута: по прямой × коэффициент дорог, уточняется реальными замерами; движок дорожной маршрутизации (OSRM/Google Directions) не подключён.
