# Android-приложение Home Master (Android 5.0+)

Нативная оболочка (Java, без сторонних библиотек) над веб-интерфейсом вашего сервера. Весь функционал — тот же, что в браузере
(графики, финансы, склад, чат, карта, скины...): обновили сервер — обновилось приложение у всех. Оболочка даёт странице то, что браузеру недоступно:

| Возможность | Как реализована |
|---|---|
| Файлы «из любого места» устройства (память, SD-карта, Google Диск) | системный выбор файлов (`onShowFileChooser`), несколько файлов сразу |
| Сохранение отчётов Excel и файлов **с выбором папки/носителя** | системное окно «Сохранить как…» (`ACTION_CREATE_DOCUMENT`); большие файлы качаются напрямую в выбранное место |
| Камера (съёмка документов в макс. качестве) | запрос разрешения + `getUserMedia` |
| GPS, трекинг | запрос разрешения во время работы; экран не гаснет, пока трекинг включён |
| Звонок коллеге, навигация к объекту | `tel:`, Google Maps открываются системными приложениями |

## Установка готового APK
1. Скопируйте `HomeMaster.apk` на телефон → разрешите «Установку из неизвестных источников» → откройте файл.
2. При первом запуске введите адрес сервера: `https://service.example.com` (без `/app`). Сменить сервер позже: Настройки → «Сменить сервер».
3. Разрешите геолокацию и камеру.

Адрес `http://192.168.x.x:8000` тоже работает (домашняя сеть), но тогда камера и точная геолокация в WebView могут быть недоступны — для полной работы нужен **HTTPS**.

## Сборка самому (без Android Studio, без скачивания SDK)
Ubuntu 22.04+/Debian 12+ (Windows — через WSL2):
```bash
sudo apt install openjdk-17-jdk-headless aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
cd android && ./build_apk.sh        # → HomeMaster.apk
```
Или в облаке GitHub: загрузите проект в репозиторий → Actions → **Build APK** → Run workflow → скачайте артефакт.

**Ключ подписи.** При первой сборке создаётся `keystore/release.keystore`. **Сохраните его** (в репозиторий не кладите): приложение, подписанное другим ключом, нельзя установить поверх предыдущего. Для GitHub положите ключ в секрет `KEYSTORE_B64` (`base64 -w0 keystore/release.keystore`). Свой ключ: `KEYSTORE=... KS_PASS=... KEY_ALIAS=... ./build_apk.sh`.

## Что можно поменять
* Название и иконка: `res/values/strings.xml`, `res/mipmap-*/ic_launcher.png`.
* Поведение оболочки: `src/org/prontofix/app/MainActivity.java` (подробные комментарии в коде).
* Версия: `AndroidManifest.xml` (`versionCode`, `versionName`).

## Ограничения (честно)
* Сборка проверена на валидность (подпись v1+v2+v3, манифест, разрешения), но **на реальном телефоне я её не запускал** — первый запуск проверьте и пришлите скриншот, если что-то не так.
* **Трекинг в фоне:** запись положения идёт, пока приложение открыто (экран остаётся включённым). Если приложение свернуть/заблокировать экран, Android может приостановить определение положения. Полноценный фоновый трекинг требует нативной службы (Foreground Service) — это отдельная доработка.
* `targetSdkVersion=28`: приложение устанавливается на Android 5–16, но не предназначено для публикации в Google Play (там требуется новее). Для установки APK-файлом это не мешает.
* Самый старый WebView на Android 5 может отображать интерфейс проще (без части современных CSS-эффектов); работоспособность сохраняется.
